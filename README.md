# My Kazakh Level — қазақ тілі деңгейін анықтайтын Telegram бот

- Студентке баратын хабарламалар — орысша, админге — қазақша.
- Тесттер: 6–10 жас және 10–18 жас — «Тамыр» мектеп жоспарының 6 сатысы бойынша;
  18+ — A1–C2 ересектер жоспарының деңгейлік тесттері бойынша (`questions.py`).
- Деңгейі бірдей 10 студент жиналғанда топ өзі құрылады, сізге тізім келеді.

## Railway-де іске қосу (күні-түні жұмыс істейді)
1. GitHub-та **жеке (Private)** репозиторий ашып, осы папкадағы файлдарды жүктеңіз.
   `.env` пен `students.db` жүктелмейді (құпия деректер).
2. railway.com → **New Project → Deploy from GitHub repo** → репозиторийді таңдаңыз.
3. Сервистің **Variables** бөліміне қосыңыз:
   - `BOT_TOKEN` — BotFather берген токен
   - `ADMIN_IDS` — сіздің Telegram ID (`/myid`)
   - `DATA_DIR` = `/data`
4. Сервисті тышқанның оң жағымен басып → **Attach Volume** → Mount path: `/data`
   (студенттер базасы осы дискіде сақталады, қайта қосқанда өшпейді).
5. **Settings → Networking → Generate Domain** — бот қосымшаны осы мекенжайда таратады
   және Telegram-ның мәзір батырмасына «Начать» өзі қояды.
6. Компьютердегі ботты (`run.bat`) өшіріңіз — бір бот екі жерде қатар жұмыс істей алмайды.
7. Ескі базаны көшіру: компьютердегі `students.db` файлын ботқа құжат ретінде жіберіңіз.

## Админ командалары
- `/stats` — статистика · `/queue` — топқа кезек (толмаған топты жабуға болады)
- `/groups` — құрылған топтар · `/export` — Excel (CSV) файл
- `/backup` — базаның көшірмесі (анда-санда сақтап қойыңыз)
- `.db` файлын ботқа жіберу — базаны сол файлмен ауыстыру (ескісі `.bak` болып қалады)

## Сұрақтарды өзгерту
`questions.py` — әр сұрақтың **бірінші** нұсқасы дұрыс жауап, бот нұсқаларды өзі араластырады.
`level_ru` / `ru` — студентке көрінетін орысша мәтін. Railway-де файлды GitHub-та өзгертсеңіз
болды — бот өзі қайта қосылады.

## Компьютерде іске қосу (қосымша)
`.env.example` → `.env` (BOT_TOKEN, ADMIN_IDS, WEBAPP_URL) → `run.bat`.
GitHub Pages қолданылса: `python build_webapp.py` → `webapp/` файлдарын қайта жүктеу.
